# 家庭物品 App 使用说明书

> 适用范围：Android 内测版（0.5.x）。本说明书随功能迭代同步更新；验收证据见 `dev-docs/acceptance.md`。

## 一、账号与登录

- 使用邮箱 + 密码注册/登录；同一账号可属于多个家庭。
- 账号登录态自动保存，App 重新打开自动进入清单（会话失效后需重新登录）。
- 内测版 APK 下载：`https://homestorag.xyz/apk/home-inventory-internal-latest.apk`（或邀请链接落地页下载）。

## 二、新用户引导

- 新注册用户首次进入清单页会看到欢迎语和步骤引导：点右下角「+ 新增」→ 点「识别名称 / 拍照」拍一件物品正面照 → 选择或新增区域 → 选择或新增位置 → 识别中可点「存入草稿箱」，也可等识别完成直接「保存」→ 打开顶部「草稿」查看草稿箱。
- 引导过程中点右上角「X」可随时跳过；跳过或完成后，之后不再自动弹出。
- 新增区域/位置时可以直接在物品表单里完成：点「＋ 新增区域 / ＋ 新增位置」，在输入框填名称后点「添加」，新区域/位置会立即出现在列表并自动选中；新增位置会默认匹配刚选的区域。

## 三、清单管理

### 区域与位置

- 顶部「区域」条 / 「位置」条：点击选中即可筛选该区域/位置的物品，再点一次取消筛选。
- 长按区域：可重命名、改颜色、删除。
- 长按位置：可重命名、重新分配所属区域、删除。
- 长按区域/位置后，编辑弹窗里可拍照或从相册选择一张主照片；有照片时可查看、替换、删除。
- 物品行里的位置名（如 `A1`）和区域名（如 `客厅`）是照片按钮：点击查看对应照片；还没照片时提示“拍照或从相册选择”。
- 只读成员只能查看区域/位置照片，不能拍摄、替换或删除。
- 条上的「+」：新增区域 / 新增位置；在添加物品弹窗里也有「＋ 新增区域 / ＋ 新增位置」，可直接输入名称即时添加，并默认带当前选中的区域。

### 物品

- 点击右下角「+ 新增」添加物品；也可以不选区域/位置直接保存，这类物品会出现在「未分配」里。
- 物品字段：名称、区域/位置、备注、过期日。
- 搜索框按名称/备注/位置搜索；右上角排序：按过期日 ↑ / ↓、按名称。
- 「物品」标题旁「未分配」按钮：只看没有选择位置（含没选区域）的物品；再点恢复全部。
- 点物品行进入编辑：可改名称/位置/备注/过期日、删除物品、查看/更换照片。

### 过期提醒

- 过期日 30 天内显示「即将过期」，已过显示「已过期」；排序默认把即将/已过期放在前面。

## 四、拍照识别

- 新增物品 → 「识别名称」：拍照或从相册选一张，自动识别并填入详细名称（尽量含品牌/规格）和一句备注。
- 「识别日期」：拍包装上的有效期，自动填入过期日（识别不到可手填）。
- 「添加照片」：给没有照片的物品补一张缩略图（只上传缩略图，不再识别名称）。
- 图片查看：点缩略图放大；大图支持双击放大 4 倍、双指捏合最多 6 倍、单指拖动。
- 照片存储：服务器只保存 200px 缩略图；识别用的清晰图保存在手机本地用于放大查看（换设备/重装后放大会退回模糊缩略图）。
- 区域/位置照片例外：每个区域、每个位置各保存一张约 1280px 的清晰图（100–300KB）；Android 本地缓存、Web 浏览器缓存，查看时本地优先，缺失才联网。

## 五、草稿箱

- 识别中就可以点「存入草稿箱」，不用等识别完成；关掉面板继续拍下一个。
- 存入后识别在后台自动完成，草稿的名称/备注会自动补上；App 回到前台或重新打开时也会自动补识别。
- 顶部「草稿」按钮（带数量角标）进入草稿列表：
  - 编辑：打开表单，改完保存即正式建档并删除草稿；
  - 保存：按当前信息直接建档；
  - 删除：丢弃该草稿；
  - 点缩略图：看大图。
- 批量导入：新增物品时先选好位置，点「批量导入」→ 一次选多张照片 → 全部自动存入草稿箱（每张后台识别）。

## 六、家庭共享

- 房主在顶部「邀请」生成邀请链接，通过微信等渠道发给家人。
- 家人打开链接 → 注册/登录 → 申请加入；房主批准后成为成员，共同查看和编辑家庭物品。
- 同一账号属于多个家庭时，点顶部当前家庭名称可切换清单；App 会记住上次选择的家庭，下次启动直接进入（当前内测版在共享家庭中先支持查看，写入仍以 Web 端为主）。
- 房主在「邀请」面板可批准/拒绝加入申请。
- 房主可移除成员（被移除后立即失去访问权，家庭数据保留）。
- 成员权限分级：`owner`（房主）/ `member`（全部权限）/ `readonly`（只读）。房主在「家庭成员」里可把成员设为「只读」或「全部权限」；只读成员只能查看区域/位置/物品及照片，不能新增/编辑/删除（服务端强制）。
- 邀请别人使用本 App：「邀请」面板里的「邀请使用 App」可分享内测版下载链接；对方下载注册后成为独立用户，不会自动进入你的家庭。

## 七、Excel 备份与导入

- 备份：顶部「备份」导出 Excel（工作表「物品清单」，表头：序号/名称/格子编号/所在区域/备注/有效期）。
- 导入：顶部「导入」选择 Excel → 先预检（不直接写库）→ 如有同格同名冲突，逐条选择 跳过/都保留/覆盖 → 提交后显示新增/覆盖/跳过/失败汇总。
- 规则：以「所在区域 + 格子编号 + 名称」判断同一物品；备注和有效期完全相同自动跳过；只写备注/有效期差异时用「覆盖」。

## 八、隐私与安全

- 数据属于家庭空间：只有家庭成员可看/改；未登录或非成员无法访问。
- 拍照识别时，照片会瞬时发送给火山引擎（豆包）处理，识别后服务器不保存原图，只保存缩略图。
- 内测阶段数据在测试环境；正式公开前会补齐隐私政策与用户协议。

## 九、常见问题

- 新增物品/格子/照片后没立即显示：0.5.18 起数据会实时刷新，也可在清单页下拉刷新。
- 识别失败/识别不准：手动修改名称、备注，过期日手动填。
- 换设备：草稿和本地清晰图不带走，物品照片放大查看会变模糊（服务器仍保留缩略图）。
- 邀请链接失效：房主在家庭设置中重新生成。
