# Home Inventory App

云端家庭物品管理应用。当前处于 MVP 基础搭建阶段。

## 技术路线

- Next.js
- TypeScript
- Supabase Auth
- Supabase Postgres + RLS
- PWA first

## 本地启动

```powershell
npm install
npm run dev
```

复制 `.env.example` 为 `.env.local`，并填入 Supabase 测试项目的公开配置。
