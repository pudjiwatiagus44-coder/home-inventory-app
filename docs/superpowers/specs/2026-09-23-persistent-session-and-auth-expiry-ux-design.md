# 长期登录与登录失效交互设计

日期：2026-09-23  
状态：设计已由用户确认，待实施计划与代码实现

## 背景

当前自托管认证会话固定 30 天过期。Android 只根据本地是否保存 `home_inventory_session` 判断登录状态；当服务端会话已过期或被撤销时，App 仍显示清单页，直到新增物品等接口返回英文 `Authentication required`。这会让用户误以为新增物品功能故障。

用户确认采用“长期设备会话 + 自动续期”：正常使用时不因固定天数被强制退出；只有主动退出、修改/重置密码、账号禁用或服务端撤销会话时才要求重新登录。

## 目标

- 已登录设备持续保持登录，不再因固定 30 天期限突然失效。
- Web 浏览器受 Cookie 保存期限约束时，通过活跃请求自动续期。
- 服务端仍是登录状态的唯一真源；客户端不能仅凭本地 Cookie 判定会话有效。
- 任何受保护接口返回 401 时，客户端清除旧凭证并回到登录页。
- 用户只看到中文提示“登录已失效，请重新登录”，不直接看到 `Authentication required`。

## 非目标

- 不取消主动退出、密码修改/重置、账号禁用或管理员撤销会话的能力。
- 不保存明文密码，不增加“自动输入密码重新登录”。
- 不改变家庭权限、用户隔离或服务端权限校验。
- 本轮不引入第三方认证、手机号登录或社交登录。

## 方案

### 服务端会话

- 新创建的设备会话不再以固定 30 天作为业务失效条件。
- `revoked_at`、用户状态和会话是否存在仍必须校验；任何一项无效都返回 401。
- 修改或重置密码后继续作废该账号已有会话，要求使用新密码重新登录。
- 数据库现有 `expires_at` 字段的兼容与迁移方式在实施计划中落实：不得直接破坏线上已有会话或绕过撤销校验。

### Web Cookie 自动续期

- 登录成功后仍使用 HttpOnly、Secure、SameSite=Lax Cookie。
- 由于浏览器会限制持久 Cookie 的最长保存期，服务端在已认证活动期间滚动刷新 Cookie 的到期时间；只要用户持续使用，登录状态持续有效。
- Cookie 缺失、会话被撤销或账号不可用时不续期，直接返回 401。

### Android 登录失效处理

- 网络层统一识别受保护接口的 401。
- 收到 401 后清除 `EncryptedSessionStore` 中的旧 Cookie，并通知应用根状态切换到登录页。
- 登录页显示一次性中文提示“登录已失效，请重新登录”。
- 不把 401 作为普通业务错误展示，也不继续用无效 Cookie 重试。

### Web 登录失效处理

- 受保护请求统一处理 401：清除客户端登录态展示，跳转 `/login`，并显示“登录已失效，请重新登录”。
- 不将服务端英文错误正文直接暴露给最终用户。

## 数据流

1. 客户端携带设备会话 Cookie 请求受保护接口。
2. 服务端按 token 哈希查找会话，并校验会话未撤销、用户可用及权限边界。
3. 有效会话继续处理请求；Web 响应按续期策略刷新 Cookie。
4. 无效会话返回 401。
5. 客户端统一清除旧会话、回到登录页并显示中文提示。

## 安全边界

- 长期登录不等于永久信任：服务端每次请求仍验证会话和账号状态。
- token 继续只以哈希形式存库；Android 继续使用加密存储；Web 继续使用 HttpOnly Cookie。
- 主动退出必须撤销服务端会话并清除客户端 Cookie。
- 密码修改/重置必须撤销该用户既有会话。
- 401 处理不得清空用户本地库存数据库或草稿；只清除认证凭证并停止向服务端同步，避免数据丢失。

## 验收标准

- 超过原 30 天期限但未撤销的会话仍可通过服务端认证。
- 已撤销、密码重置后、账号禁用或不存在的会话仍返回 401。
- Web 活跃登录会刷新持久 Cookie；缺失或无效会话不会续期。
- Android 在新增物品、刷新清单或其他受保护请求收到 401 后自动返回登录页并显示中文提示。
- Web 在受保护请求收到 401 后进入登录页并显示相同中文提示。
- 用户界面不再显示 `Authentication required`。
- 重新登录后可以正常新增物品，原本地草稿和库存缓存不被 401 处理删除。
- 自动化测试覆盖长期会话、撤销会话、密码重置、Cookie 续期以及 Web/Android 401 处理。

## 发布约束

认证和线上数据库属于高风险边界。完成本地实现和测试后，生产部署前必须备份数据库与当前应用，验证迁移可回滚，并再次取得用户对生产部署的明确授权。
